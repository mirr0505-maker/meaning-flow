# Meaning Flow 베타 사용 안내

> **베타 기간**: 가입일부터 **30일**
> **베타 인원**: 10명 내외 (한국)
> **버전**: v1.0.0 (Android + iOS MVP)

함께해주셔서 고마워요. 이 글은 Meaning Flow 베타에서 무엇을 할 수 있는지, 어떻게 도움을 주실 수 있는지 안내드리는 짧은 편지입니다.

---

## 1. Meaning Flow 는 어떤 앱인가요?

**의도적으로 잘 살아가는 것** 을 도와주는 IN(내향 직관형) 친화 앱입니다.

- 일반 To-Do 앱처럼 **할 일을 쌓아두지 않습니다**. 압박을 주지도 않습니다.
- 대신 두 가지를 함께합니다.
  - **두 자아** — 혼자일 때의 나 / 함께일 때의 나 를 인정하기
  - **하루의 흐름** — 점화(아침) · 실행(낮) · 통합(저녁) · 착륙(밤) 4시간대 모드
- 핵심 5가지:
  1. **2분 마이크로 변환기** — 너무 큰 일은 작은 한 걸음으로 잘라요
  2. **70% 완료 버튼** — "완벽" 아니어도 충분해요
  3. **의미 일기** — 오늘 한 줄, 본인을 위한 짧은 회고
  4. **공명의 정원** — 익명으로 한 줄을 흘려보내고, 다른 분의 한 줄에 🌿 공명 한 번
  5. **생각 보관함** — 밤에 머리가 멈추지 않을 때, 잠깐 옮겨두기

## 2. 설치 안내

### Android (Google Play 내부 테스트)
1. 받으신 **베타 가입 링크**를 Android 폰 브라우저에서 열기
2. "베타 테스터로 참여" 동의 → Google Play 가 자동으로 앱 페이지로 이동
3. **설치** 버튼 → 첫 부팅
4. (베타 종료 후 자동으로 일반 버전으로 전환)

### iOS (TestFlight)
1. App Store 에서 **TestFlight** 검색 → 설치 (이미 있으면 건너뛰기)
2. 받으신 **TestFlight 초대 링크**를 iPhone 의 Safari 에서 열기
3. **"Meaning Flow 받기"** → TestFlight 앱이 자동 실행
4. **설치** → 첫 부팅
5. 홈스크린 아이콘에 작은 노란 점(베타 표시) 이 보이면 정상

> **막힐 때**: 두 OS 모두 첫 부팅 시 동의 화면 → 두 자아 선택 → 닉네임 받는 흐름은 동일합니다.

> **이메일 등록 절차**: 베타는 운영자가 받은 이메일을 ASC/Play Console 에 등록한 후 설치 링크를 보내드리는 방식입니다. 처음 받으신 카톡/메일에 사용하실 이메일 1개 (Android = Google 계정 / iPhone = Apple ID) 만 회신해주세요. 등록 후 5~10분 내 설치 링크 보내드립니다.

## 3. 30일 베타 흐름

| 시점 | 일어나는 일 |
|------|----------|
| **D-day (가입일)** | 첫 부팅 → 데이터 처리 동의 → 두 자아 선택 → 조합 닉네임 받음 → 메인 사용 시작 |
| **D+1~29 (일상 사용)** | 자유롭게 일기 · 정원 · 생각 보관함 사용 |
| **D+30 (베타 종료)** | 앱 진입 시 "30일의 흐름을 함께 흘려보냈어요" 화면으로 안내 |
| **종료 후** | 본인 데이터(의미 일기·생각·정원의 글) 모두 **그대로 보존**. 정식 출시 시 다시 만날 수 있어요 |

> **베타 사용자 혜택 (정식 출시 시)**: 첫 사용자에게 따뜻한 인사를 준비하고 있어요. 정확한 내용은 정식 출시 직전 알려드릴게요.

### 30일이 지나기 전에 꼭 해주세요 (선택)
- **설정 → 내 데이터 → JSON 으로 내보내기** — 본인 일기를 손에 한 부 가져가실 수 있어요. 종료 후에도 동일 메뉴에서 가능합니다.
- **설정 → 계정 연결 → Google 계정 연결하기** — 디바이스를 바꾸거나 잃어버리셔도 일기가 안전하게 다시 만나져요.

## 4. 사용법 — 4가지 모드

### 🌅 점화 (06–10시) — 어제 예약한 첫 단추 하나
어젯밤에 예약한 "내일의 첫 단추" 가 있다면 그걸 보여드려요. 작은 한 가지부터 흐름을 시작해요.

### ☀️ 실행 (10–18시) — 지금 할 단 하나
- 할 일 한 가지만 적어요 (여러 개 X)
- 너무 크면 "2분 안에 시작할 수 있나요?" 가 묻고 → 더 작은 단위 3가지 옵션 제안
- 끝나면 **70% 완료** 또는 100% 완료 선택. 70% 가 디자인상 더 강조됩니다 — 충분히 잘하신 거예요

### 🌆 통합 (18–22시) — 오늘의 한 줄
- 의미 일기 — 오늘 한 줄로 회고. 한 단어여도 충분해요
- 공명방 토글 ON 으로 켜면, 익명으로 정원에 흘러갑니다 (단방향 — 댓글·좋아요 없음)
- 정원에서 다른 분의 한 줄에 **🌿 공명해요** 한 번 가능 (취소도 가능)
- 외국어 글에는 🌍 번역 버튼 (월 100회 한도)
- 어제 이미 정원에 흘려보낸 글이 있으면 "수정해서 보낼게요" 가 부드럽게 안내합니다

### 🌙 착륙 (22–02시) — 4가지 작은 의식
- **생각 보관함** — 머리가 멈추지 않으면 단어 하나만 옮겨두고 "찰칵 — 잠그기"
- **5분 영감 타이머** — 아이디어가 멈추지 않을 때 5분만 쏟아내요
- **내일의 첫 단추** — 내일 점화 모드에서 만날 2분짜리 하나 예약
- **이불 모드** — 4초 들숨/4초 날숨 호흡, "당신은 충분히 잘하고 있어요"

## 5. 공명의 정원 안전 안내

이 곳은 **익명 광장**이에요. 위급한 상황에서는 전문 기관과 먼저 연결되어야 합니다.

### 자동 안전 장치
- 게시 전 자동 모더레이션 (욕설·혐오 표현 자동 차단)
- 자해 표현 감지 시 즉시 위기 상담 핫라인 안내
- 자해 신고 1회면 우선 처리, 일반 신고 3회면 자동 숨김

### 위기 자원 (24시간 무료)
- **자살예방상담전화**: **1393**
- **정신건강위기상담**: **1577-0199**
- **청소년전화**: **1388**
- **응급**: **119**

> 일기 작성 중에 마음이 무거운 표현이 있으면 앱이 부드럽게 한 번 안내합니다. 일기는 차단하지 않아요. 본인에게는 항상 남아요.

## 6. 데이터 안전 약속

- **의미 일기·생각 보관함**: **본인만** 볼 수 있어요 (Supabase Row Level Security). 운영자도 직접 열람 불가
- **공명방 게시물**: 익명 닉네임(두 자아 조합)만 노출. 실명·프로필 사진·정확한 게시 시각 노출 X
- **다른 사용자가 공명한 사람이 누구인지 작성자에게 노출 X** — 합계 숫자만
- **계정 삭제** (설정 → 계정 삭제) 시 모든 본인 데이터 영구 삭제
- **분석 도구** (Sentry · PostHog) — 첫 부팅 시 동의 선택. 본문은 절대 보내지 않음. 메타데이터(언어·시각)만

## 7. 알림 (선택)

- 정원에서 본인 글에 공명 받으면, **아침 6시 1회 합산**해서 알려드려요
- 기본 **OFF** — 정원 화면 상단의 🌿 토글로 ON
- 압박 안 주려고 디자인했어요. 받기 싫으시면 그대로 두셔도 됩니다

## 8. 베타 피드백 — 가장 큰 도움

이 30일 동안 알려주시면 가장 큰 도움이 되는 것들:

### 🪶 정서 톤
- 어느 워딩이 어색한가? 명령형으로 느껴진 곳?
- "괜찮아요"·"충분해요" 가 진짜 따뜻하게 닿았는지

### 🪶 흐름
- 4시간대 자동 전환이 자연스러운가?
- 의미 일기 → 공명방 → 정원 흐름이 부드러웠는지

### 🪶 정원
- 다른 분 한 줄을 봤을 때 어떤 마음이었는지
- 자해/위기 자원 안내가 너무 무겁거나 부족했는지

### 🪶 자해 안전 흐름
- 일기 작성 중 자해 키워드가 감지된 경우, 안내가 어떤 톤이었는지 (너무 과한지 / 무관심한지)

### 🪶 버그
- 어떤 화면에서 멈췄거나 이상한가?
- 30일 만료 안내가 부드러운지

### 📬 피드백 채널 — Google Form

📝 **베타 피드백 폼**: __________  *(베타 시작일에 링크 보내드려요)*

- 한 번에 다 채울 필요 X. 떠오를 때마다 한 항목씩 보내주셔도 OK
- 카테고리: 정서 톤 / 흐름 / 정원 / 안전 흐름 / 버그 / 자유 의견
- 응답 시간 평균 **2~5분**. 익명도 가능 (이메일 칸 비워두기)

또는 앱 안 → **설정 → 내 데이터 → JSON 으로 내보내기** → 폼의 "파일 첨부" 자리에 같이 보내주시면, 어떤 흐름이었는지 운영자가 함께 볼 수 있어요 (본인 본문은 직접 검토 후 첨부 — 강요 X).

## 9. 자주 묻는 질문

**Q. 30일 후에 일기가 사라지나요?**
A. 아니요. **본인에게는 그대로 남아요**. 정식 출시 때 같은 자리에 있어요. 종료 화면에서 "내 데이터 내보내기" 로 한 부 가져가시는 것도 권장드려요.

**Q. 한국어 외에 다른 언어로 쓸 수 있나요?**
A. 베타는 **한국어 · 영어 · 일본어** 3개를 지원해요 (앱 우상단 언어 토글). 일본어는 1차 초안이라 거슬리는 표현이 있을 수 있어요. 알려주시면 다듬어요.

**Q. 공명방 글을 신고하면 어떻게 되나요?**
A. 자해 신고 1회 → 우선 검토. 일반 신고 3회 누적 → 자동 숨김. 본인 화면에선 즉시 숨겨져요.

**Q. 내 일기를 다른 사람이 볼 수 있나요?**
A. **공명방 토글 ON** 으로 명시적으로 게시할 때만 익명으로 보여요. 그 외엔 본인만 봅니다.

**Q. 안드로이드 외 다른 기기는요?**
A. **Android + iOS** 둘 다 지원합니다. iPhone 은 TestFlight 로 설치해요. PC/태블릿 은 정식 출시 때 합류해요.

**Q. iPhone 의 TestFlight 앱이 뭐예요?**
A. Apple 이 만든 베타 테스트용 앱이에요. App Store 에서 무료로 받으실 수 있고, 베타 끝나면 그냥 그대로 두시거나 지우셔도 됩니다. TestFlight 로 설치한 앱은 90일마다 새 빌드를 받게 되는데, 이번 베타 30일 동안은 그 안에 들어요.
