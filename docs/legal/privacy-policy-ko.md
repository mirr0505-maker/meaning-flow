## 1. 처리방침의 목적

__________ (이하 "회사")는 모바일 애플리케이션 "**Meaning Flow**" (이하 "서비스") 이용자의 개인정보를 소중히 다루며, 본 처리방침을 통해 수집·이용·보관·제3자 제공·이용자 권리 등을 투명하게 안내합니다.

본 처리방침은 한국 개인정보 보호법(PIPA), 유럽 일반 개인정보 보호법(GDPR), 일본 개인정보 보호법(APPI)에 따른 의무 사항을 포함합니다.

## 2. 수집하는 개인정보 항목

### 2.1 필수 수집 (서비스 동작에 필수)

| 항목 | 수집 시점 | 보관 위치 | 목적 |
|------|---------|---------|------|
| 익명 사용자 ID (UUID) | 첫 부팅 시 자동 생성 | Supabase (서울 region) | 본인 데이터 식별 |
| 두 자아 조합 (Solo/Social MBTI) | 온보딩 시 이용자 선택 | Supabase | 모드별 프롬프트 분기 |
| 의미 일기 본문 | 이용자가 저장할 때 | Supabase | 본인 회고 기록 |
| 생각 보관함 본문 | 이용자가 저장할 때 | Supabase | 본인 임시 메모 |
| 할 일 (tasks) | 이용자가 등록할 때 | Supabase | 점화/실행 모드 흐름 |
| 정원 게시물 (resonance_posts) | 이용자가 공명방 토글 ON 시 | Supabase | 익명 광장 노출 |
| 디바이스 timezone | 알림 동의 시 | Supabase | 사용자 timezone 06시 알림 발송 |
| Expo Push Token | 알림 동의 시 | Supabase | 푸시 알림 발송 |

### 2.2 선택 수집 (이용자 동의 후에만)

| 항목 | 보관처 | 목적 | 거부 시 |
|------|--------|------|--------|
| 에러 stack trace, 디바이스 OS·모델 | **Sentry** | 앱 버그 추적·수정 | 데이터 미수집, 앱 동작 정상 |
| 사용 이벤트 (기능별 익명 사용 통계) | **PostHog** | 어느 기능이 도움되는지 분석 | 데이터 미수집, 앱 동작 정상 |

**중요**: Sentry/PostHog 에는 의미 일기·생각·정원 게시물의 **본문이 절대 전송되지 않습니다**. 오류 메시지·이벤트 종류·메타데이터(언어·char_count)만 전송됩니다.

### 2.3 SNS 계정 연결 시 (이용자 명시적 선택 시에만)

| 항목 | 출처 | 보관 |
|------|------|------|
| 이메일 주소 | Google OAuth | Supabase auth.users |
| Google 계정의 user identifier | Google OAuth | Supabase auth.users |
| (Apple 추가 시) Apple ID | Apple Sign In | Supabase auth.users |

SNS 계정 연결은 이용자가 SettingsScreen 에서 명시적으로 선택해야 발생합니다. 회사는 SNS 의 다른 정보(친구 목록·게시물 등)에 접근하지 않습니다.

## 3. 수집한 정보의 이용 목적

| 목적 | 사용 데이터 |
|------|-----------|
| 의미 일기·생각·정원 등 핵심 기능 제공 | 본문, 사용자 ID, timezone |
| 익명성 보호 | 두 자아 조합 닉네임만 노출, 사용자 ID 비공개 (Row Level Security) |
| 자동 모더레이션 | 정원 게시물 본문 (OpenAI Moderation API 일회성 전송) |
| 자해 키워드 안내 | 입력 본문에 키워드 매칭 (서버 전송 없이 디바이스에서 처리) |
| 번역 (이용자 요청 시) | 정원 게시물 본문 (DeepL/Google Translate API 일회성 전송) |
| 1일 1회 합산 공명 알림 (이용자 ON 시) | 어제 게시물의 공명 수 합계 |
| 앱 버그 수정 (Sentry 동의 시) | 에러 stack trace |
| 사용 분석 (PostHog 동의 시) | 익명 이벤트 통계 |

### 4.2 국외 이전 동의

회사는 위 수탁사 중 일부가 해외에 위치하므로 개인정보를 국외 이전합니다. 이용자는 첫 부팅 시 ConsentScreen 에서 본 사항에 동의합니다. 동의 거부 시 일부 기능(번역·모더레이션·SNS 연결 등)이 제한됩니다.

### 4.3 법적 요구에 의한 제공

회사는 법령에 의한 정당한 요구가 있는 경우에만 개인정보를 수사기관에 제공합니다. 그 외에는 어떠한 경우에도 이용자의 동의 없이 제3자에게 제공하지 않습니다.

## 6. 이용자 권리 (GDPR·PIPA·APPI)

이용자는 다음 권리를 자유롭게 행사할 수 있습니다.

| 권리 | 행사 방법 |
|------|---------|
| **열람권** (GDPR 15조) | 앱 내 본인 데이터 화면에서 직접 조회 |
| **정정·삭제권** (GDPR 16·17조, "잊혀질 권리") | 앱 내 설정 → 계정 삭제 (즉시 영구 삭제, cascade) |
| **이동권** (GDPR 20조, "데이터 이동권") | 앱 내 설정 → 내 데이터 → JSON 으로 내보내기 |
| **처리 제한·이의 권리** (GDPR 18·21조) | 앱 내 설정 → 분석 도구 토글 OFF |
| **동의 철회권** | ConsentScreen 의 모든 동의는 SettingsScreen 에서 철회 가능 |

## 7. 안전성 확보 조치

| 영역 | 조치 |
|------|------|
| **데이터 분리** | Supabase Row Level Security (RLS) — 본인 user_id 의 row 만 read/write 가능. 다른 이용자·회사 직원도 의미 일기·생각 본문을 직접 열람 불가 |
| **전송 암호화** | TLS 1.3 (Supabase API), HTTPS (모든 외부 API 호출) |
| **저장 암호화** | Supabase 의 PostgreSQL TDE(Transparent Data Encryption) |
| **비밀키 분리** | Service Role Key 는 Supabase Edge Function 내에서만 사용, 클라이언트 노출 X. Supabase Vault 로 보관 |
| **모더레이션 보호** | 자동 모더레이션 후에만 정원 게시. 자해 키워드 시 우선 위기 자원 안내 |
