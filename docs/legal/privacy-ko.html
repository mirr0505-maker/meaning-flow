개인정보처리방침

Meaning Flow 개인정보처리방침 · 시행일 2026-05-29 · 최종 개정 2026-05-29

Meaning Flow(이하 "회사")는 회원의 개인정보를 소중히 다루며, 「개인정보 보호법」, GDPR, APPI 등 관련 법령 및 규정을 준수합니다. 본 방침은 회사가 어떤 개인정보를 어떻게 수집·이용·보관·파기하는지 안내합니다.

1. 수집하는 개인정보 항목

1.1 회원가입 시 자동 수집

  • SNS 인증 정보 — Google 또는 Apple 의 사용자 식별자(UID), 이메일, 표시 이름(공개된 경우)
  • Apple "이메일 가리기" 사용 시 — privaterelay.appleid.com 형태의 가상 이메일

1.2 서비스 이용 중 사용자가 입력

  • 두 자아 정체성(혼자일 때 / 함께일 때 MBTI 16가지 중 선택)
  • IN 특성(8가지 중 1개 이상 선택)
  • 닉네임(자동 조합 또는 직접 입력, 30자 이내)
  • 의미 일기(하루 한 줄 회고, 200자 이내) · 본인만 열람
  • 실행 모드 일/세부 일(100자 이내)
  • 첫 단추(다음 날 아침 예약 행동)
  • 생각 보관함(전두엽 보관)
  • 공명방 게시물(공명방에 보내기 토글 선택 시) · 익명 게시

1.3 자동 생성 / 수집

  • 고유 사용자 식별자(UUID) · Supabase 자동 부여
  • 접속 일시(가입일, 최근 로그인 일시)
  • 기기 정보(OS, 앱 버전) · 분석 도구 동의 ON 시
  • 오류 로그 · Sentry 동의 ON 시 (실제 의미 일기 본문 등은 절대 포함 안 됨)
  • 사용 통계 · PostHog 동의 ON 시 (이벤트 이름과 메타데이터만, 본문 X)

1.4 수집하지 않는 정보

  • 실명, 주민등록번호, 전화번호, 주소
  • 위치 정보(GPS 등)
  • 연락처, 사진 라이브러리, 캘린더 등 기기 내 다른 앱 데이터
  • 광고 식별자(IDFA / GAID)

2. 수집 방법

  • 회원의 SNS 로그인 시 OAuth 응답으로 자동 수집
  • 회원이 앱 내에서 직접 입력
  • 분석 도구(Sentry, PostHog) — 회원이 명시적으로 동의 토글 ON 시에만

3. 수집 목적

  • 회원 식별 및 인증
  • 서비스 제공 (To-Do 기능, 의미 일기, 공명방 등)
  • 공명방 모더레이션 (부적절한 콘텐츠 차단)
  • 위기 자원 자동 안내(자해 키워드 감지 시)
  • 서비스 품질 개선(동의 ON 시)
  • 오류 추적 및 디버깅(동의 ON 시)
  • 법적 의무 이행 및 분쟁 대응

4. 보유 및 이용 기간

  • 회원의 정보는 회원 탈퇴 시까지 보유합니다.
  • 회원 탈퇴 요청 시 모든 본인 데이터는 즉시 영구 삭제됩니다(회복 불가). 단, 관련 법령에 따라 일정 기간 보존이 필요한 정보(예: 법적 분쟁 기록)는 해당 기간 동안 분리 보관 후 파기합니다.
  • 공명방 게시물 중 회원이 삭제하지 않고 회원 탈퇴 시에도 영구 삭제됩니다(작성자 user_id가 cascade 로 함께 삭제).
  • 익명 통계(개인 식별 불가 형태)는 서비스 개선 목적으로 별도 보관할 수 있습니다.

5. 제3자 제공

회사는 회원의 개인정보를 회원의 동의 없이 외부 제3자에게 제공·판매하지 않습니다. 단, 다음의 경우는 예외입니다:

  • 회원이 사전에 동의한 경우
  • 법령에 의한 요청(법원의 영장 등)이 있는 경우

6. 개인정보 처리 위탁

회사는 서비스 운영에 필요한 범위 내에서 다음 제3자에게 처리 업무를 위탁하고 있습니다. 위탁 업체는 모두 회사의 위탁 계약 또는 그에 준하는 약관에 따라 회원의 개인정보를 안전하게 처리합니다.

7. 정보주체의 권리

회원은 언제든지 다음의 권리를 행사할 수 있습니다:

  • 열람 — 회원 본인의 모든 데이터 확인. [설정 → 내 데이터 내보내기] 에서 JSON 형식으로 다운로드 가능.
  • 수정 — 정체성(MBTI, 닉네임, IN 특성), 의미 일기 등 직접 수정 가능.
  • 삭제 — [설정 → 회원탈퇴] 로 본인 데이터 영구 삭제(GDPR 17조 잊혀질 권리).
  • 이동 — 내 데이터 내보내기로 JSON 형태로 이동 가능(GDPR 20조).
  • 동의 철회 — Sentry/PostHog 토글로 분석 도구 동의를 언제든 철회.
  • 처리 제한 / 이의 제기 — 본 방침 하단 이메일 주소로 연락.

8. 개인정보 자동 수집 장치

회사는 광고 식별자, 쿠키, 웹비콘 등을 사용하지 않습니다. 분석 도구(Sentry, PostHog)는 회원이 명시적 동의 토글 ON 시에만 활성화되며, 토글 OFF 시 자동으로 데이터 수집을 중단합니다.

9. 만 14세 미만 아동 보호

회사는 만 14세 미만 아동의 회원가입을 허용하지 않습니다. 만 14세 미만 아동이 가입한 사실이 확인된 경우 즉시 해당 계정을 삭제하고 보호자에게 안내합니다.

10. 보안 조치

회사는 회원의 개인정보를 보호하기 위해 다음 조치를 시행합니다:

  • 모든 통신은 HTTPS 로 암호화
  • Supabase Row Level Security(RLS) 로 회원 본인의 데이터에만 접근 허용
  • 비밀키(service_role, API 키, JWT 등)는 client 에 노출되지 않으며 Edge Function 또는 환경변수로 분리 관리
  • 공명방 게시물은 작성자 식별자(user_id)를 SELECT 결과에서 제외하는 VIEW 로 익명성 보장
  • 접근 권한 분리 및 정기 점검

11. 국가별 데이터 이전

회원의 데이터는 위 6항의 수탁 업체에 따라 대한민국, 미국, EU 등에 저장될 수 있습니다. 회사는 각 수탁자가 적정한 보호 수준을 유지하도록 계약 또는 표준 약관을 통해 보장합니다.
