# Meaning Flow — UX/UI 자가 점검 보고서

> 작성 시점: 2026-05-23 (v1: 초안 / **v2: 사용자 피드백 반영 — 2026-05-23 갱신**)
> 관점: 월드와이드 앱 전문가 + IN 정서 친화 (M1~M7) + 글로벌 스토어 정책 (App Store / Play Store)
> 범위: 현재 Phase 3 ~ 4 진행 시점의 모든 화면

## ⚠️ v2 핵심 수정 사항 — M1~M7 적용 범위 재정의

**v1 보고서의 과보호 문제**: 메인이 M1~M7 을 자해 안전·공명방 단방향·위기자원 같은 핵심 안전 영역 **외**에까지 과하게 적용함. 일반 todo list / 게시판 / 정체성 발견 흐름 도입을 막아 앱 정체성이 흐려짐.

### 앱 정체성 (사용자 결정 2026-05-23)
**Meaning Flow = IN 친화 todo list**. 의미 일기·공명방·생각 보관함은 부속 안전망. **핵심**: "완벽 추구 → 시작 못 함" + "뇌가 부스터 달린 듯 아이디어 폭주" 같은 IN 특성을 가진 사람의 **할 일 시작·완료를 도와주는 앱**.

### M1~M7 정확한 적용 범위
- **M1 압박 회로 차단** = "스트릭·이번 달 X개 완료!" 같은 **압박형 통계만 금지**. 일반 todo 체크 / 할 일 누적 표시 / 회고용 리스트는 **OK**
- **M3 공명방 단방향** = **공명방 한정**. 자유 게시판은 별도 기능으로 양방향 도입 가능 (정식 출시 시점에)
- **M4 자해 안전·모더레이션** = 그대로 강하게 (공명방·일기 작성 시점)
- **M6 본인만 read** = reflections/thought_vault 한정. 게시판/todo list 는 다른 정책
- **M2 권유형 카피** = 모든 화면에 그대로 유지

본 보고서는 메인 세션이 코드 베이스를 직접 점검한 결과다. 사용자 결정이 필요한 항목을 ⚠️ 로 표시했다.

## 1. 화면별 점검

### 1.1 첫 부팅 흐름

| 단계 | 화면 | 점검 결과 |
|------|------|---------|
| 1 | App.tsx loading | ActivityIndicator 만. 5초 이상 걸릴 경우 사용자가 답답 → 권장: "잠깐만요..." 카피 추가 |
| 2 | ConsentScreen (4-J) | ✅ M2 톤 우수, M3 능동적 진입 정합 |
| 3 | (제안) **환영 화면** | ❌ **없음** — 사용자 피드백 ① 핵심. "익명으로 시작" / "Google 로 시작" 선택권 명시 권장 |
| 4 | Onboarding intro | ✅ "당신은 게으른 게 아니에요" 카피 강함. "다른 연료로 움직이는 엔진" 메시지 명확 |
| 5 | pickSolo / pickSocial | ◐ MBTI 잘 모르는 사용자엔 부담 — 사용자 피드백 ②. 간이 테스트 옵션 부재 |
| 6 | combo 결과 | ✅ "당신은," → 조합 닉네임 명시. 다만 이후 메인에서 닉네임 자주 안 보임 (피드백 ③) |

### 1.2 4시간대 모드 (Main)

#### 🌅 점화 (MorningScreen)
- ✅ "어젯밤 예약한 첫 단추" 흐름 잘 작동
- ✅ "오늘 ____ (으)로 흘러가요" 정체성 카피 정합
- ◐ 첫 단추 없을 때 빈 화면 카피 ("괜찮아요. 저녁 모드에서 내일의 첫 단추를 예약하게 됩니다.") 정합

**개선 권장**:
- 화면 헤더에 조합 닉네임 작게 노출 (피드백 ③)
- 어제 한 줄 일기 1줄 미리보기 (오늘 시작 시 어제 회고 환기 — 일기 아카이브 ④ 와 자연 연결)

#### ☀️ 실행 (DayScreen)
- ✅ "2분 마이크로 변환기" + "70% 완료" 강조 — M1 정확
- ⚠️ **사용자 피드백 ⑥ — 할 일 누적 안 됨**: 사용자가 인지 못한 흐름 = "내일 아침 첫 단추 → 다음날 점화 모드 등장" 이 카피로 명시 안 됨. **권장**: NightFirst 의 "예약 완료" 안내 강화 + 다음날 morning 진입 시 "어제 예약한" 강조
- ◐ 한 가지 끝나면 "다른 한 가지 적어보기" — 다음 작업 추가 가능. 단 todo list 형태 X — M1 의도

**개선 권장 (보수적)**:
- 오늘 끝낸 일 하단에 작게 누적 표시 (체크리스트 X, "오늘 흘러간 것들" 같은 회고 형태) — 사용자 피드백 ⑦ 의 절충안

#### 🌆 통합 (EveningScreen + EveningTabs)
- ✅ 의미 일기 + 공명방 토글 + 자해 키워드 모달 + 중복 게시 안내 — 매우 정밀
- ✅ Garden 진입 면책 + 알림 토글 + 푸시 안전
- ◐ **일기 이력 부재** (피드백 ④) — 다음 STEP 으로 가장 시급

**개선 권장**:
- 통합 모드 안에 새 탭 "내 흐름" 또는 "지난 한 줄들" — 일기 아카이브
- 빈 상태 카피 따뜻하게

#### 🌙 착륙 (NightScreen + 4 sub-tab)
- ✅ NightVault, NightTimer, NightFirst, NightBlanket 모두 정합
- ◐ NightFirst 4 옵션 — 사용자 피드백 ⑤. PRD 원안 유지 권장. 다만 옵션 라벨 다듬기 가능 ("물 한 잔 마시기" → "물 한 컵, 그게 다예요" 같은 더 IN 톤)
- ◐ NightBlanket 의 "당신은 충분히 잘하고 있어요" 카피 강함 ✅

### 1.3 공명의 정원 (GardenScreen + GardenPostCard)
- ✅ 면책 카피 + 알림 토글 + 필터 칩 + 단방향 공명 + 모더레이션 + 신고 + 자해 자원 — **현재 가장 정밀한 화면**
- ✅ 번역 onDemand + 캐시 + 한도 — PRD 정합
- ◐ 처음 사용자는 "왜 한 줄만?" "왜 댓글 없나?" 질문 가능 — **About 화면에서 설명 필요** (피드백 ⑩)

### 1.4 SettingsScreen
- ◐ 진입점이 헤더 우상단 작은 ⚙ — 발견 어려움. **권장**: 첫 부팅 후 1회 "여기에 설정 있어요" 안내 또는 ⚙ 옆에 라벨
- ✅ 데이터 export · 분석 도구 토글 · 계정 연결 · 약관 · 계정 삭제 — 모든 필수 항목
- ❌ **두 자아 변경 / 조합 닉네임 변경 부재** (피드백 ⑧)
- ❌ **About / 앱 소개 부재** (피드백 ⑩)
- ❌ **언어 변경 메뉴** — 우상단 토글로만 가능, 설정에 모음 필요
- ❌ **알림 설정 모음** — 정원 화면 토글만 있음. SettingsScreen 에도 미러링 필요

### 1.5 LockedScreen
- ✅ 정서 카피 + 데이터 export 우선 + 안심 메시지 — 매우 정합
- ◐ "정식 출시 알림 받기" 카드가 현재 placeholder — 채널 URL 채워야 (베타 사용설명서와 정합)

## 4. 발견된 우선순위 v2 (Top 10) — 사용자 피드백 반영

### MVP 출시 전 — ★

| 순위 | 항목 | 분량 | 비고 |
|------|------|------|------|
| ★ 1 | **IN 특성 리스트 + 자기 선택 흐름** | 중간 | 앱 정체성 핵심. 온보딩 강화 + About 메뉴. "내가 IN 인가? IN 이면 뭐지?" 자기 발견 |

| ★ 8 | **카피 sweep** — dev 잔재 제거, 빈 화면 강화 | 중간 | 완성도 |
| ★ 9 | **베타 사용설명서 채널 URL** + 4-I 정책 본문 호스팅 | 사용자 측 | 출시 직전 필수 |

## 5. IN 특성 후보 (★ 1 작업용)

PRD/UserGuide + 사용자 명시 사항 통합. 카피는 권유형 (M2):

| 특성 | 라벨 카피 (한국어 초안) |
|------|--------------------|
| 뇌 부스터 / 아이디어 폭주 | 🧠 뇌가 부스터 달린 듯, 아이디어가 멈추지 않아요 |
| 완벽 추구 → 시작 차단 | 🌀 머릿속 시뮬레이션이 다 끝나야 손이 움직여요 |
| 깊이 우선 | 🔍 표면적인 얘기보다 의미 있는 한 줄을 찾아요 |
| 혼자 시간 필요 | 🪟 사람들 사이에선 에너지가 빨려요 |
| 의미가 연료 | 🎯 "왜?" 가 명확해야 움직일 수 있어요 |
| 직관·패턴 포착 | 🌌 점들 사이의 선이 보여요 |
| 시뮬레이션 → 행동 차단 | 💭 시작 전에 결과까지 다 그려져 멈춰요 |

## 6. 결론 및 다음 액션

**MVP 출시 전 ★ 1~8 처리 권장**. ★ 1 (IN 특성) + ★ 2 (todo list) 두 가지가 앱 정체성 핵심.

### 권장 진행 순서
1. **STEP 1**: ★ 1 (IN 특성 리스트 + 자기 선택) — 앱 정체성 강화
2. **STEP 2**: ★ 2 (풀 todo list) — 앱 정체성 두 번째 축
3. **STEP 3**: ★ 4 (일기 아카이브) — 핵심 가치
4. **STEP 4**: ★ 3, 5, 6, 7 묶음 (About / Settings / 환영 / Header) — 작은 항목 한 번에
5. **STEP 5**: ★ 8 (카피 sweep)
6. **사용자 측**: ★ 9 (정책 호스팅 + 베타 채널)

각 STEP 1.5~3시간 분량. STEP 1·2·4 끝나면 MVP 출시 직전 UX 완성도 +60% 예상 (v1 의 +30% 보다 큼 — 앱 정체성 강화가 핵심 차이).
